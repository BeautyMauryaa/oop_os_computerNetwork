# 5. Most Important Tricky Interview Questions
These are the facts I would revise before attempting the assessment.

| Question | Correct understanding |
| :--- | :--- |
| Can a class have multiple objects? | Yes |
| Is inheritance an IS-A relationship? | Yes |
| Is composition a HAS-A relationship? | Yes |
| Which OOP pillar provides data hiding? | Encapsulation |
| Which OOP pillar hides implementation? | Abstraction |
| Does Python support multiple inheritance? | Yes |
| Does Java support multiple class inheritance? | No |
| Can multiple threads share memory? | Yes, within the same process |
| Does every process have its own address space? | Normally yes |
| What causes deadlock? | Four Coffman conditions together |
| What prevents starvation? | Aging is one solution |
| Does paging cause external fragmentation? | No, not in conventional paging |
| Can paging cause internal fragmentation? | Yes |
| Is TCP connection-oriented? | Yes |
| Is UDP connectionless? | Yes |
| Does TCP guarantee ordered delivery? | Yes |
| Does UDP guarantee delivery? | No |
| Which protocol translates domains into IPs? | DNS |
| Which port does HTTPS use by default? | 443 |
| Which port does HTTP use by default? | 80 |
| Is HTTPS encrypted? | Yes, using TLS |
| Is HTTP stateless? | Yes, by default |
| Is PUT idempotent? | Yes |
| Is POST idempotent? | Generally no |
| Which layer handles routing? | Network layer |
| Which layer uses TCP and UDP? | Transport layer |
